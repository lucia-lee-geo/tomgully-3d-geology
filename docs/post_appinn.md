# 推荐：一套免费开源软件，能替代几十万的矿业三维建模软件

> 发布平台：小众软件论坛 · 分类：软件推荐

## 太长不看

矿业公司做三维地质建模和储量估算，传统上要花几十万买 Leapfrog / Surpac / Datamine。
我实测了一整套**免费开源软件**，能跑通同样的主流程，成本 0 元，而且全程脚本化、可复现、可审计。

软件清单：Python + GDAL + gstlearn + pyvista（外加几个科学计算库），全免费、跨平台。

## 这几款软件分别干嘛

| 软件 | 一句话 | 替代谁 |
|---|---|---|
| **gstlearn** | 地质统计学：变差函数、克里金 | Surpac / Datamine 的地统模块 |
| **pyvista + VTK** | 三维体元/网格可视化与导出 | Leapfrog 的三维显示 |
| **GDAL / rasterio / pyogrio** | 栅格、矢量读写与投影 | 各种 GIS 底座 |
| **scikit-gstat** | 轻量变差函数备选 | 同上 |

都是命令行/脚本工具，没有花哨 GUI，但**代码即文档**——每一步怎么算的，看得见、改得动。

## 我用真实矿区数据跑了一遍

选了澳大利亚北领地一个金矿（Tom's Gully），数据全是政府开放平台免费下的（钻孔、化验、地形）。
结果：从原始钻孔数据到三维块体模型、吨位×品位估算，五步脚本全通。

关键数字：584 个金样段 → 三维变差函数 → 克里金 → 块体模型 → 约 1.3 万盎司的浅层资源量级
（和官方报告差一个数量级，原因写在边界里，不吹）。

## 踩到的坑（对想入坑的人最有用）

1. 数据库里数值列被存成 TEXT，`WHERE ... BETWEEN` 静默返回 0 行不报错——排查半天。
2. gstlearn 建三维空间有个函数名坑，会悄悄建出四维。
3. 一个叫 `glo30` 的 DEM 文件其实是 8 角秒（241 m），不是 30 m。
4. 矿区「RL 高程」和海平面高程差了 986 m，混用矿体直接飞天。
