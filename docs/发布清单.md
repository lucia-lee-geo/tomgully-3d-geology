# 四平台发布清单

> 交付物与四个发布平台的对应关系，及每平台发布要点。

## 总原则

- **GitHub 仓库是唯一事实源**：代码 + 数据溯源 + README 全在这里，其余三平台从它派生。
- 原创论点主线：**开源全栈复刻商业矿业软件工作流**；佐证坑点见 `docs/原创发现.md`。
- 每篇都带「边界声明」：可验证的讲清楚，模棱两可的讲清边界。

## 平台映射

| 平台 | 受众 | 物料 | 形式 | 标题建议 |
|---|---|---|---|---|
| **GitHub** | 全球开发者 | 本目录（README + pipeline/ + docs/ + model/ + output/） | 开源仓库 | 三维地质建模与储量估算（开源全栈） |
| **稀土掘金** | 中文开发者/数据工程 | `docs/article_juejin.md` | 技术长文 | 用开源 Python 栈复刻 Leapfrog：三维地质建模与储量估算全流程（0 元成本） |
| **小众软件论坛** | 小众/免费软件爱好者 | `docs/post_appinn.md` | 软件推荐贴 | 推荐：一套免费开源软件，能替代几十万的矿业三维建模软件 |
| **GIS Stack Exchange** | 全球 GIS 从业者 | `docs/gis_se_qa.md` | 自问自答 Q&A | How to build a 3D geological model and estimate resources with only open-source tools? |

## 发布要点

### GitHub
- 仓库结构已就绪；README 已含结果速览、管线、边界、原创发现。
- 推送前：确认 `source/` 不入库（原始大文件只读留本机），`pipeline/ docs/ model/ output/ estimate/ processed/` 入库。
- 建议加 `LICENSE`（MIT）+ 一句英文摘要（README 顶部已有中文，补英文 abstract 更利于 GIS SE 读者跳转）。

### 稀土掘金
- 直接贴 `docs/article_juejin.md`，配 `output/tomgully_blockmodel.png` 作封面。
- 文末附 GitHub 链接；标签：Python / 数据工程 / 三维 / 开源。

### 小众软件论坛
- 贴 `docs/post_appinn.md`，配两张截图（块体模型 + 岩性体元）。
- 突出「0 元替代几十万」；附 GitHub 链接；语气轻松，少术语。

### GIS Stack Exchange
- 用 `docs/gis_se_qa.md` 的 Q&A，**自己提问 + 自己回答**（SE 允许 self-answer，须是真实问题）。
- 标签：`python` `geology` `geostatistics` `3d` `qgis`。
- 答案里附可复现代码 + 边界声明；链接 GitHub 仓库。

## 发布顺序建议

1. 先 GitHub（事实源就位）。
2. 掘金（中文深度长文，引流到 GitHub）。
3. 小众软件（软件推荐，引流）。
4. GIS SE（英文 Q&A，扩大国际读者）。
